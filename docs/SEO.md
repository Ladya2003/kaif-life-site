# Языковые версии и SEO

## Адреса

- Русский: `/`, `/stories/`, `/stories/{slug}/`.
- Английский: `/en/`, `/en/stories/`, `/en/stories/{slug}/`.
- Испанский: `/es/`, `/es/stories/`, `/es/stories/{slug}/`.

Русские адреса сохранены. Всего 21 основная страница: главная, список историй и пять статей на каждом языке. Переведено полное содержание, а не только меню. Переводы находятся в исходниках и попадают в готовый HTML при статической сборке. Автоматического перенаправления по языку браузера нет. Переключатель сохраняет текущую страницу.

## Что настроено

- Собственный canonical для каждой языковой версии, без параметров запроса.
- Взаимные `hreflang=ru/en/es` и `x-default` на русскую версию той же страницы.
- Корректный `html lang` и локализованные title, description, Open Graph и Twitter Card.
- JSON-LD: Person, WebSite, WebPage/CollectionPage, BlogPosting, ImageObject и BreadcrumbList. Статья связана с автором, издателем и своей HTML-страницей.
- Отдельные превью статей 1200×630 для Open Graph/Twitter; указаны размер, тип и описание изображения.
- Для BlogPosting подготовлены отдельные изображения 16:9, 4:3 и 1:1. Файлы находятся в `public/images/previews/`; полные кадры вписаны в фон без изменения фотографий в теле статей.
- Видимые хлебные крошки в списке и статьях.
- `sitemap.xml` содержит все 21 основной URL и исключает страницы ошибок.
- `robots.txt` с адресом sitemap; основные страницы разрешены к индексации, ошибки помечены `noindex`.
- Локализованные alt и подписи фотографий. Изображения имеют width/height, адаптивные размеры и локальные WebP-файлы. Первое фото загружается приоритетно, остальные — отложенно.
- Вертикальные фото внутри статей показываются целиком. Для обоих состояний фотопары проверяются естественные пропорции и отсутствие пустого участка до подписи.

Даты публикации и изменения статей не добавляются в разметку без подтверждённых дат. Реальные даты можно будет добавить вместе с публикацией или обновлением материала. Метрики аудитории и отзывы не выдумываются.

## Проверка

`npm run check`, `npm run build`, `npm run test:seo`, `npm run test:smoke`.

`test:seo` читает готовые файлы из `dist/`, проверяет полный статический текст, уникальность title/description, соответствие canonical и sitemap, взаимные языковые ссылки, изображения и JSON-LD. Он включён в GitHub Actions перед загрузкой артефакта Pages. Проверка не требует браузера или выполнения JS сайта.

Локальные проверки подтверждают наличие и согласованность разметки, адресов и переводов. Они не подтверждают включение в индекс Google, появление расширенных результатов или позиции в выдаче.

После публикации на kaif-life.com:

1. Подтвердить владение доменом в Google Search Console.
2. Отправить `https://kaif-life.com/sitemap.xml`.
3. Проверить по одной главной и статье каждого языка через URL Inspection.
4. Проверить опубликованные статьи в Rich Results Test и исправлять реальные замечания.
5. Следить за индексированием и запросами по языкам; расширять материалы на основе собственных поездок и опыта автора.

Настройки Google Search Console, GitHub Pages и DNS в этой работе не менялись. Подтверждение домена и индексацию нельзя выполнить локально.

## Применение рекомендаций из проекта Amorely

- Генерация HTML и метатегов до JavaScript уже выполняется Astro. Исходный HTML содержит основной видимый текст, без скрытого блока `.seo-bootstrap`.
- Три согласованных языка имеют собственные URL и полный перевод статей.
- Разметка соответствует личному блогу автора. Organization, SoftwareApplication, DigitalDocument, отзывы и FAQ не добавляются без соответствующего реального содержимого.
- `meta keywords` не добавляется: Google не использует его при индексации и ранжировании.
- `lastmod`, datePublished и dateModified не выставляются текущим временем каждой сборки. Их можно добавить после появления достоверных дат публикации и содержательных обновлений.
- Внутренних приватных маршрутов приложения на этом статическом сайте нет. Все три страницы ошибок имеют noindex, исключены из sitemap.
- Код Amorely в рамках этой проверки не изменялся; использован присланный владельцем разбор.
